☕ Excited to share my latest full-stack project: BeanCraft — an artisan specialty coffee e-commerce web application!

I built this application from scratch using clean HTML5, CSS3, and Vanilla JavaScript on the frontend, powered by a robust Node.js & Express.js backend and MongoDB with Mongoose for data persistence.

🚀 Key Features & Architectural Highlights:
✨ Interactive Coffee Quiz: A 3-step sensory matcher that recommends personalized single-origin roasts and blends based on user preferences.
✨ Dynamic Roastery Catalog: Instant search with debouncing, category & roast-level filtering, and price sorting.
✨ Real-Time Bag Drawer & Customizer: Bag size multiplier calculation (250g, 500g, 1kg), custom grind options, and a free shipping progress bar with localStorage synchronization.
✨ Multi-Method Checkout: Address validation, dynamic promo code engine (e.g. COFFEE10), and simulated payment options (Card, UPI, Cash on Delivery).
✨ Live Order Tracking Stepper: 4-stage fulfillment tracking (Placed ➔ Roasting ➔ Shipped ➔ Delivered) with receipt generation and order tracking codes.
✨ Admin Portal & Inventory Operations: Real-time sales metrics, order status updater, full product CRUD, and database seeding tools.
✨ Security & Persistence: JWT authentication, bcrypt password hashing, and Mongoose schema validation.

🛠️ Tech Stack:
• Frontend: HTML5, CSS3 (Custom Variables, Flexbox/Grid, Glassmorphism), Vanilla JavaScript (ES6+)
• Backend: Node.js, Express.js (REST APIs, Error Handling Middleware)
• Database: MongoDB, Mongoose ODM
• Authentication: JWT (JSON Web Tokens), bcryptjs

Building this deepened my understanding of state synchronization, RESTful API architecture, and creating intuitive user experiences.

I would love to hear your thoughts and feedback! 💬👇
